# The Cleaner

A browser shooter. A man in a suit walks a rain-soaked city block at night with a Glock while attackers rush him from both sides.

**Play:** open `index.html` in a browser. It's a single file with no install or build step, so it also works as-is on GitHub Pages.

## Controls
- **Mouse:** aim
- **Click / Space:** shoot
- **R / right-click:** reload (17-round magazine)
- **A / D:** walk back / hurry forward
- **P / Esc:** pause
- **M:** mute

## How it plays
- Every third attacker triggers **slow motion** when hit. The world turns black-and-white and the camera punches in on each bullet impact and follows the body. Keep shooting him (up to 5 hits) and watch the bullets fly and the blood spray.
- Everyone else drops from a single shot, and how they fall depends on where you hit them:
  - **Head:** dies instantly and flies backward
  - **Chest:** drops straight down
  - **Knee:** falls forward onto his face
- Gunmen show up later. A red laser sight warns you before each shot.
- Finishing a slow-motion kill restores 1 HP.
